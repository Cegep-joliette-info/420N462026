# PHP

PHP est très similaire à JavaScript: c'est un langage interprété et faiblement typé. Historiquement, PHP n'était pas orienté objet, nous pouvons encore voir des traces de cette ère. Lorsqu'une fonctionnalité est disponible en fonction ou en objet, nous allons utiliser les objets.

PHP est un language open-source et très dynamique. J'ai déjà codé un script qui créait un autre fichier PHP avant de l'exécuter! Les fichiers PHP ont .php comme extension. Habituellement, la page d'accueil s'appel index.php, similaire au index.html d'une page web standard.

Pour travailler avec PHP, vous avez besoin d'un interpréteur et d'un serveur Web. Sur n'importe quelle plateforme, vous pouvez installer le tout avec Docker. Sur Unix, vous devez installer Apache (ou NGINX) avec le module PHP. Sur Windows vous pouvez installer la même chose, installer le module PHP sur IIS ou installer WAMP/XAMPP. Si vous avez PHP d'installé, PHPStorm peut partir un serveur Web. Je conseil aussi d'installer le module PHP XDEBUG, ça permet le déverminage avec PHPStorm (non testé) ou de mettre plus beau vos prints.
