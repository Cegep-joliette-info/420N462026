# Atelier 1 - Tailwind CSS

Ouvrez mon [corrigé](../../corriges/1-revision/1-tailwind.html) (sans trop regarder le code) et testez la réactivité en redimensionnant la fenêtre et testez les `hover` et `focus`. Remarquez aussi que le mode sombre est supporté automatiquement.

![Image de la page](../../images/atelier-1-1.png)

## Étape 1 - Exploration

Prenez 1 heure pour essayer de reproduire la page en utilisant Tailwind CSS. Le texte dans les projets ne sont pas importants.
Ne prenez pas plus de temps, l'objectif est de se familiariser avec Tailwind CSS, pas de le connaître parfaitement.

## Étape 2 - AI

Avec votre outil d'assistance au développement par IA préféré (GitHub Copilot, Claude Code, Gemini, etc.), essayez de générer le code HTML nécessaire pour reproduire la page précédente en utilisant Tailwind CSS.

## Étape 3 - Analyse

Comparez votre code avec le corrigé. Notez les différences et les similitudes. Essayez de comprendre pourquoi certaines approches ont été utilisées dans le corrigé.

Analysez aussi le code généré par l'IA. Que font les classes utilisées? Sont-elles efficaces? Y a-t-il des erreurs ou des améliorations possibles?
